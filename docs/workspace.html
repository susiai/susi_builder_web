Workspace

Back up, restore, or reset the files and settings stored in this browser.

Backups and recovery

Download projects, settings, run activity, saved editor drafts, and conversations. API keys stored for this tab are excluded. Browser storage is tied to this origin and can be cleared by the browser.

Backups include model settings. Browser model files can be downloaded again after restoring.

Backups download as unencrypted ZIP files with a 128 MiB unpacked limit.

Reset workspace

Reset Default Files restores files from vfs-preload, including config.json. Other files, conversations, and console history are kept.

Clear deletes the workspace database, saved conversations, and console history for this address.

Clear?

Files supplied in vfs-preload will be restored, including config.json and the default Skills. This replaces edits to those files. Other files and folders, conversations, console history, and session credentials are kept.

This permanently deletes the workspace database, including apps, files, settings, downloaded models, and the restore safety backup. It also clears saved conversations, console history, and session credentials. Opening a page such as Explorer starts a fresh workspace with the default files.

Replace the workspace with this backup?

Projects, configuration, saved editor drafts, and conversations will be replaced. Stop agent runs first. The current workspace will be retained as the previous restore safety backup. All other workstation pages will reload. External browser actions cannot be undone by a backup.
