Available models

WebGPU runs first, with WASM as a fallback. Model files download as needed.

Ollama is the recommended API option for running larger models locally.

  • Install Ollama. Get the desktop app for your system from ollama.com.
  • Allow browser connections on macOS. Run this in Terminal, then quit Ollama and reopen it. 
    launchctl setenv OLLAMA_ORIGINS "*"
  • Allow browser connections on Windows. Quit Ollama from the system tray, open Edit environment variables for your account, and create a user variable named OLLAMA_ORIGINS with the value *. Reopen Ollama from the Start menu. Windows walkthrough
  • Download a model. Run one of these commands in Terminal or PowerShell.
    • ollama pull lfm3:1.7b-q4_K_M
    • ollama pull gemma4:e4b-it-qat
    • ollama pull gemma4:12b-it-qat
    • ollama pull qwen3.6:35b-a3b-q4_K_M
    • ollama pull qwen3.8:27b-mtp-q4_K_M
    • ollama pull inkling-2-mini:26b-a5b
  • Connect SUSI Builder.
    Type http://localhost:11434 into the API host field.
    Leave the API key blank and choose Check connection.
