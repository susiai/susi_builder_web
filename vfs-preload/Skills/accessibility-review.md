# Review a web page for accessibility

**Find this skill for** accessibility, keyboard, focus, semantic HTML, mobile, Barrierefreiheit, Tastatur.

1. Inspect the page in its normal viewport and at a narrow width. Check whether content wraps and controls
   remain usable.
2. Navigate with Tab and Shift+Tab. Confirm the focus indicator is visible and the order follows the page.
3. Activate links and buttons by keyboard. Check that dialogs close with Escape and return focus to the trigger.
4. Check accessible names for inputs and icon buttons. Read headings in order and check status and error messages.
5. Report each observed issue with the page, affected control, reproduction steps, and a focused fix.
