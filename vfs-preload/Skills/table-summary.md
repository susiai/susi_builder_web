# Inspect and summarize a table

**Find this skill for** CSV, JSONL, Parquet, analysis, data quality, Tabelle, Daten, Zusammenfassung.

1. Open the file in Table. Identify its columns, record count, units, and the meaning of a single row.
2. Check missing values, duplicates, and inconsistent formats. Keep identifiers such as postal codes as text.
3. For a group comparison, state the grouping column and denominator. Show counts alongside percentages.
4. Save any cleaned data under a new name unless the user asked to overwrite the original. Explain what changed
   and cite the file used for the summary.
